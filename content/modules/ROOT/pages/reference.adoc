== Useful Commands

Verify Portworx cluster status:
[source,sh,role=execute]
----
pxctl status
----

List all Portworx volumes:
[source,sh,role=execute]
----
pxctl volume list
----

Watch Autopilot rule events:
[source,sh,role=execute]
----
oc get events --field-selector involvedObject.kind=AutopilotRule \
  --all-namespaces --sort-by .lastTimestamp \
  -o custom-columns=MESSAGE:.message
----
